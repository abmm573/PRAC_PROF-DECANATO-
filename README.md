# Práctica Profesional – Facultad de Ciencias Sociales

Este repositorio contiene los proyectos desarrollados durante la **Práctica Profesional** realizada en la **Facultad de Ciencias Sociales**.

Se han desarrollado **tres sistemas independientes**, organizados en diferentes ramas del repositorio para una mejor gestión y mantenimiento.

---

## Estructura del Repositorio

El repositorio está organizado en las siguientes ramas:

* `ControlAsistencia` → Sistema de control de asistencia
* `AppAcademica` → Aplicación académica
* `RevistaDigital` → Sistema de revista digital

Cada rama contiene su propio `README.md` con instrucciones específicas de ejecución.

## Cómo usar este repositorio

1. Clonar el repositorio:

   ```bash
   git clone <URL_DEL_REPOSITORIO>
   ```

2. Cambiar a la rama del proyecto deseado:

   ```bash
   git checkout ControlAsistencia
   ```

3. Leer el `README.md` de esa rama para ejecutar el sistema.
